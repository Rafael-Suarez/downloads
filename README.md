# downloads

Release files for the tools offered at **https://rafael-suarez.com/downloads**.

This repository holds installers only. The page there finds the newest release here by itself, so publishing a release is all it takes to update it.

| Tag prefix | Tool |
| :--- | :--- |
| `scribe-` | Scribe, local transcription for Windows |
| `anthology-` | Anthology, a Windows media app (called Shelf, tag `shelf-`, until 1.6.0) |

The installers are not code-signed, so Windows SmartScreen warns the first time one runs: **More info → Run anyway**.
